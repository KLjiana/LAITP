# LAITP 变更记录（按里程碑）

编制日期：2026-11-19；最近更新：2026-11-23

状态：交接、教学与验收辅助记录。本文只汇总**开发机已有证据支持**的交付与草案，**不构成验收结论**。检测（M3）尚未实现。

## 1. 说明

### 1.1 用途

本文按 M0–M5 里程碑归并仓库现有变更，供交接方、教师和验收方快速了解三件事：已经交付了什么、验证到什么程度、哪些内容仍只是规划或草案。每条能力都附相对路径的证据文档；具体字段、数字或命令若与本文不一致，以被链接的文档为准。

### 1.2 阅读边界

- **“已验证”只限本开发机**：不表示目标 Windows 机器、普通用户权限、真正断网环境、课堂真实数据或板端硬件已经验收（见第 4 节）。
- **不代替验收清单**：[目标机离线验收清单](acceptance-checklist.md) 是 A1–A15 的判定依据。本文不改变任何验收项状态，也不把本机证据写成目标机通过。
- **检测未实现**：M3 的检测契约、Schema、数据清单、校验脚本和决策建议均是草案、规划或建议稿，未激活、未决策，不能当作可用能力（见 3.4 节）。
- **摄像头测试已停止**：摄像头自动化测试自 2026-11-18 起按要求停止；本文只保留此前的历史记录。
- **不冻结易过期数值**：分发包版本、体积与 SHA-256 不在本文硬编码，统一以[离线分发包](offline-bundle.md)及同名 `.sha256` 文件为准。
- 本文只新增记录，不修改代码、其它文档或构建产物。

| --- | --- |

## 4. 已知限制

- **目标机与权限**：干净 Windows 机器与解压双击尚未验收（对应目标机 A1–A9 等）；普通用户权限对应 A13，未验证。见[目标机离线验收清单](acceptance-checklist.md)与[项目状态报告](status-report.md)。
- **真正断网**：仅以清空 PATH、清除 Python 变量、代理指向不可用地址的方式模拟，未在断网机器或防火墙全阻断环境验收（A12）。见[离线分发包](offline-bundle.md)。
- **课堂真实数据**：尚未采集；真实数据结论只来自公开 Fashion-MNIST 3 类子集（A10），不能代表课堂图片与课堂效果。见[真实公开数据验证](real-data-validation.md)。
- **物理摄像头**：`HD Webcam` 状态为 Error、Code 22（设备已禁用）；历史结论仅来自 DroidCam 虚拟摄像头；自动化测试自 2026-11-18 起按要求停止，A11 仍为部分完成。见[摄像头能力](camera.md)。
- **板端**：K230/K210 无硬件、无固定工具链、无转换产物与板端运行记录（A15）。见[K230 板端可行性准备](k230-feasibility.md)。
- **检测**：M3 检测标注、数据清单、训练、导出、电脑推理/评估、消息载荷、转换与板端运行均未实现；草案与规划不能视为能力。见[检测课可行性规划](detection-feasibility.md)与[检测契约扩展与标注/结果格式草案](detection-contract-draft.md)。
- **本机数字与自动化**：性能、准确率、耗时和界面自动化结果仅代表开发机，不替代目标机人工验收与课堂现场记录。见[验证证据索引](verification-evidence.md)与[M0 本机性能与离线验证](performance-m0.md)。
- **摄像头步骤已停跑**：后续本机验证不再运行 `--camera`，默认使用 16 步套件；摄像头相关结论保留历史记录。见[项目状态报告](status-report.md)。
