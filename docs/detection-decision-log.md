# 检测决策登记表（Q1–Q8，待决策）

本文是 [检测待决问题决策建议（Q1–Q8）](detection-decisions.md) 的**配套登记表**：建议稿给出选项与理由，本表用于 lead/课程负责人在真正拍板时**逐项登记**（日期、负责人、决定、修改点）。

状态：**全部待定，检测未实现、未激活**。本表不替任何人做决定；在“决定”列为空时，任何建议都不具备约束力。

## 使用方式

1. 决策前阅读 [检测待决问题决策建议](detection-decisions.md) 对应小节与 [检测契约草案](detection-contract-draft.md) 第 5 节。
2. 拍板后把该行“决定”改为 `采纳建议` / `修改后采纳` / `否决`，填写日期与负责人，并在“修改点/备注”写明与建议的差异。
3. 按 [检测契约扩展与标注/结果格式草案 §1.2](detection-decisions.md) 的更新要求，同步修改 Schema/文档/生产方/消费方/验证，并升级版本号。
4. 八项全部登记后，才进入 P2 定稿（R6.2）；未登记项继续视为阻塞。
